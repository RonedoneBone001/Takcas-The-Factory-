Напиши веб-приложение на Python (Flask). На одной странице должно быть текстовое поле (textarea). Пользователь вводит текст, нажимает кнопку, и приложение отправляет этот текст в локальную модель Ollama через HTTP API. Затем приложение показывает краткое содержание (суммаризацию) этого текста на той же странице. Каждый запрос и его суммаризация должны сохраняться в локальную базу данных SQLite с отметкой времени. Добавь базовую валидацию: отклоняй пустой ввод и текст длиннее 5000 символов. Если модель Ollama недоступна, покажи понятное сообщение об ошибке. Никакой авторизации, никаких внешних зависимостей кроме Flask и requests. Включи файл requirements.txt и короткий README с инструкцией по запуску.
ВАЖНО: Запрос к Ollama должен идти на локальный адрес http://127.0.0.1:11434/api/generate методом POST. В JSON-теле должны быть поля "model": "qwen2.5:3b" и "prompt": текст. Ответ читай из поля "response". НЕ ИСПОЛЬЗУЙ внешние URL (типа api.ollama.ai) и НЕ ТРЕБУЙ API-ключи. Это локальный сервер.
